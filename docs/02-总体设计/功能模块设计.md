# 功能模块设计（初版）

本文件记录模块化单体的初版职责划分。各模块已有不同程度的实现，当前范围和验收进度见[需求追踪矩阵](../00-项目管理/需求追踪矩阵.md)与[测试执行记录](../05-测试/测试用例及执行记录.md)。

| 模块 | 职责与主要关系 | 主要需求 |
| --- | --- | --- |
| 身份与设置 | 注册、登录、退出、会话及个人设置；为其余私有模块提供身份与归属判断 | FR-001、002；NFR-001、002 |
| 文献与文件 | 文献元数据、导入解析、去重提示、PDF 校验及授权读取、文献笔记；向卡片提供来源 | FR-003～007；NFR-006 |
| 卡片与标签 | 独立/关联卡片、历史版本、关联关系、标签及筛选；输出图谱数据 | FR-008～012 |
| 规则与任务 | 事件、结构化条件和动作、定时检查、幂等及执行日志；调用标签、文献和通知模块 | FR-017～020；NFR-013、017 |
| 计划、通知、统计 | 提醒和已读状态、阅读计划、真实工作台和按明确口径生成周报 | FR-021～023 |
| AI 与草稿 | 私有配置及加密密钥、选材与发送提示、外部请求、草稿/来源及人工确认 | FR-013～016；NFR-004、015 |
| 导出 | 从授权卡片集或草稿和关联文献生成 Markdown、LaTeX、BibTeX | FR-024 |
| 分享与批注 | 维护分享范围、期限、撤销及批注权限；访客访问与批注，所有者处理反馈 | FR-025、026；NFR-003 |
| 通用基础 | MySQL 事务及迁移、参数验证、统一异常、日志、限流、分页、配置 | NFR-005、007～010、014、016 |

公共 API 的输入和输出、错误码、权限及事务边界应在详细设计明确。数据访问必须由服务端绑定所有者；跨模块操作不得通过接收客户端提交的用户 ID 绕过授权。

后续迭代计划增设研究项目空间，并扩展证据链、个人备份恢复、回收站、结构化阅读和批量操作；职责与依赖见 [后续迭代架构与依赖](后续迭代架构与依赖.md)。这些设计不表示功能已实现，也不改变首版验收范围。
