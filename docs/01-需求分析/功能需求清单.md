# 功能需求清单

来源：用户开发提示词。优先级定义见《软件需求规格说明书》；验收要点是预期而非实际结果，全部尚未执行。相关用例见《用例说明》；未列具体用例者在测试阶段补齐。

| 编号 | 需求及可验证验收要点 | 优先级 |
| --- | --- | --- |
| FR-001 | 注册、登录、退出和当前会话：有效凭据可进入个人工作台；未登录或会话失效访问私有资源时被拒绝并得到明确提示。 | P0 |
| FR-002 | 个人设置：用户可查看和修改支持的账户设置；不能查看或修改其他账户设置。 | P1 |
| FR-003 | 文献创建：可手工录入、导入 BibTeX、上传 PDF、输入 DOI 或链接；解析失败时仍可手工填写。 | P0 |
| FR-004 | 文献字段包含标题、作者、年份、DOI、刊会、摘要、原始链接、BibTeX 原文或重建信息、关联 PDF、阅读状态、标签及创建/更新时间；状态包括待读、阅读中、已读、已归档。 | P0 |
| FR-005 | 文献列表及详情支持搜索、筛选、编辑和删除；删除前说明关联卡片和文件处理方式并要求确认。 | P0 |
| FR-006 | 导入时优先按规范化 DOI 检查重复，无 DOI 时按规范化标题等提示疑似重复；不确定时用户确认，不自动合并。 | P0 |
| FR-007 | 在文献详情预览上传的 PDF 并管理文献笔记；选中文本可创建关联卡片，无法选择时可手工输入。 | P0 |
| FR-008 | 卡片可关联文献或独立创建，保存标题、类型、正文、标签、可选来源文献/页码/原文、用户备注及创建/更新时间；类型含概念、方法、结论、问题、想法和其他。 | P0 |
| FR-009 | 卡片支持列表、详情、创建、编辑、删除及按关键词、类型、标签和来源筛选；关联来源可跳转文献。 | P0 |
| FR-010 | 修改卡片后保留历史版本，用户可查看以往版本；独立卡片也适用。 | P0 |
| FR-011 | 用户可建立卡片间相关、支持、反驳、延伸关系；图谱显示节点和关系，点击节点可查看卡片，并处理空图谱和大量数据反馈。 | P0 |
| FR-012 | 标签支持创建、重命名、删除、添加至文献或卡片及移除，并可筛选；同用户仅大小写或首尾空格不同的名称不可重复。 | P0 |
| FR-013 | AI 设置支持 API 地址、模型、超时和密钥配置；仅拥有者管理密钥，前端不再次展示完整密钥。 | P0 |
| FR-014 | AI 以用户选择材料支持综述草稿、研究问题或阅读提问、标签推荐、文本基础格式检查；请求前显示发送范围及外部服务告知。 | P0 |
| FR-015 | AI 输出标为草稿并保留来源；用户可编辑、接受或丢弃，建议经确认才应用；不得虚构参考文献或标记为已核实事实。 | P0 |
| FR-016 | 未配置、错误配置、超时和服务失败分别给予明确提示；无真实配置不得伪造成功调用。 | P0 |
| FR-017 | 工作流规则包含名称、启用状态、触发条件、可选过滤条件、动作和创建/更新时间；支持创建、编辑、启停和删除。 | P0 |
| FR-018 | 支持文献创建、文献状态变化、卡片创建和定时检查触发；动作至少支持添加标签、更新文献状态、创建站内提醒。 | P0 |
| FR-019 | 提供待读超时提醒、已读加标签和特定类型新卡片加标签的基本规则模板。 | P1 |
| FR-020 | 规则执行记录触发时间、对象、结果和失败原因；重复事件避免重复副作用，规则链不会无限循环。 | P0 |
| FR-021 | 用户可查看站内提醒并标记已读，支持待读超时提醒。 | P1 |
| FR-022 | 用户可设置阅读计划并查看进度；工作台显示真实文献总数及待读、阅读中、已读数量、卡片总数、最近卡片和待处理提醒。 | P0 |
| FR-023 | 周报基于真实记录显示本周新增文献数、新增卡片数和已读文献数，并说明统计口径；无准确数据不编造。 | P1 |
| FR-024 | 卡片集或综述草稿可导出 Markdown 和基础 LaTeX，并可导出 BibTeX、依据关联文献生成基础参考文献；保留来源并正确处理 LaTeX 特殊字符。 | P0 |
| FR-025 | 用户为明确选择的卡片集或草稿创建只读分享，设置过期时间、允许批注与否，并可主动撤销。 | P0 |
| FR-026 | 有效分享访问者仅查看授权内容；允许时可提交关联内容并带时间的批注；分享者可查看和处理收到的批注。 | P0 |
| FR-027 | 首版稳定并验证后，可扩展用户审核的 AI 卡片聚类、更丰富的规则模板与图形配置、跳转 PDF 原文位置及周/月趋势等统计。 | P2 |
