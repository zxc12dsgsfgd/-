# 用户角色与使用场景

基于用户提供的需求整理，未开展用户调研。私有资源的所有权由服务端验证。

| 角色 | 目标 | 授权范围 |
| --- | --- | --- |
| 普通用户 | 管理科研材料、规则、计划和草稿；分享选定内容 | 仅本人私有数据及本人创建的分享 |
| 分享访问者 | 在链接有效期内阅读被授权的内容；允许时批注 | 指定分享范围；不可访问其他私有资源 |

| 场景 | 触发与期望结果 | 异常或边界 |
| --- | --- | --- |
| 文献入库 | 手填、BibTeX、DOI/链接或 PDF 形成可管理记录 | 解析失败可手填；疑似重复须用户判断 |
| 阅读沉淀 | 预览 PDF，选中文本或手输创建附来源卡片 | 无法选中文本时手动输入；独立卡片允许无来源 |
| 知识组织 | 检索筛选卡片、编辑历史、建立关系并查看图谱 | 空列表及空图谱应有反馈 |
| 自动处理 | 新建或状态变更触发规则，定时检查生成提醒 | 失败可查，重复事件不产生重复副作用，防止循环 |
| AI 草稿 | 用户选材、查看发送范围、调用外部服务、审核编辑 | 未配置、超时或失败明确提示；不得伪造成功 |
| 分享成果 | 明确选择卡片集或草稿，设置有效期及批注权限 | 过期、撤销或越权请求不能访问，禁止泄露范围外数据 |
| 跟踪进展 | 设阅读计划，查看真实统计和周报 | 无数据时显示空状态，不编造统计 |
