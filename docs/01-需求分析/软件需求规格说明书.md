# 软件需求规格说明书（初版）

日期：2026-11-20；状态：需求分析初版，待后续设计和用户审阅。依据为用户提供的开发提示词及补充要求，并非访谈或调研结果。需求编号、验收要点和优先级以同目录《功能需求清单》《非功能需求》为准；用例及项目管理目录下的追踪矩阵提供关联。所有验收均未执行。

## 1. 目标和边界
知研云枢面向科研人员的个人知识管理，以文献和知识卡片串联阅读、组织、规则处理、AI 辅助草稿、人工审核、导出和授权分享。首版在本地运行，核心数据经真实后端和 MySQL 持久化；不把硬编码演示数据作为唯一来源。

首版包括认证与个人工作空间、文献/PDF、笔记与卡片、版本与关联图谱、标签、工作流、通知、阅读计划与周报、AI、导出、分享与批注。AI 卡片聚类、更丰富的规则模板和图形配置、跳转 PDF 原文位置及更丰富统计属于核心闭环验证后的扩展，不视为已交付。基本规则模板和 PDF 预览及文本选择建卡仍属于首版。

不训练或微调模型；不将生成内容作为已核实事实；AI 不能未经用户确认修改数据。部署目标为可复现的本地演示，不暗示已部署上线。

## 2. 用户与主要流程
普通用户注册登录后管理本人数据。分享访问者通过有效令牌访问被明确选择的材料，在授权时提交批注。用户可以手动或导入文献、上传并阅读 PDF、创建可溯源卡片、组织与关联卡片、运行规则和阅读计划、选材生成草稿并审核、导出或分享。具体路径与异常见《用户角色与使用场景》和《用例说明》。

## 3. 验收与优先级
- P0：首版安全边界、核心闭环或验收必需；先于 P1 交付。
- P1：提示词明确要求的首版能力，仍须交付和验证，并非自动延期。
- P2：提示词指定核心稳定后再实施的扩展；本轮暂缓。

首版验收包括：注册登录；手工创建或 BibTeX 导入文献；上传打开 PDF；选中文本或手工创建关联卡片；标签检索；编辑与查看历史；建立并查看关系；创建和触发规则；阅读计划看板；配置真实 AI 后生成、编辑并保留来源；Markdown 与 BibTeX 导出；分享和批注；第二账号隔离；执行自动化测试。没有真实 AI 服务时，该项记为未完成真实联调，不能伪造成功。每项需记录实际结果。

## 4. 外部条件与假设
MySQL、uv 和 Python 虚拟环境由用户指定；版本和本机可用性待检查。外部 AI 服务由用户配置，材料会发送至相应提供方；依赖真实服务的验收受可用配置影响。PDF 文本选择与解析受文件及浏览器能力影响，必须提供手工替代。上传上限、限流阈值、会话时长、定时检查周期、删除及备份具体策略尚未确定，设计时确定并记录，不能视为已实现。周报时间边界、时区和“已读数”的事件口径待设计确定并向用户说明。

项目名称暂按本提示词采用“知研云枢”，旧记忆中另有名称，正式命名待确认。没有实际用户调研、性能测试或服务联调证据。
