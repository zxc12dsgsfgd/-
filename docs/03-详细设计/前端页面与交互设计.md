# 前端页面与交互设计（初版）

此为文字交互设计，未制作页面或视觉稿。遵循用户选择，进入实际界面设计时使用 unslop skill；桌面优先并支持常见平板和手机宽度。

| 页面 | 核心交互与状态 |
| --- | --- |
| 登录/注册 | 表单及字段错误，登录失败使用统一提示；过期会话提示并返回登录。 |
| 工作台 | 数据库真实统计、最近卡片、提醒及计划进度；加载、空和失败状态可恢复。 |
| 文献库/详情 | 搜索筛选、手填、BibTeX/DOI/链接导入预览及重复候选；详情编辑、文件上传和删除影响确认。 |
| 文献阅读 | PDF 预览、笔记、选择文本创建关联卡片；选择不可用时手动填入摘录和页码。 |
| 卡片/图谱 | 按关键词、类型、标签和文献筛选；编辑及版本历史；关系与可点击图谱，空图谱和数据量限制可见。 |
| 工作流/通知 | 结构化表单、规则模板、启停及执行记录；提醒列表和已读状态。 |
| 计划/周报 | 选择文献、日期与目标；显示分子分母、时区及周报统计口径。 |
| AI/草稿 | 显示提供方和发送材料，确认后执行；显示状态、来源、编辑/接受/丢弃；失败提示和重试风险。 |
| 分享/批注 | 明确选材、到期时间和允许批注，创建后显示一次链接；撤销确认；访客仅见快照及允许的批注框。 |
| 设置 | 工作台顶部的个人设置可编辑显示名称。保存成功后立即更新账户摘要。AI 配置独立展示，密钥替换和删除有明确反馈。 |

## 共同交互
异步操作显示加载与成功或失败反馈；危险操作显示影响与确认；表单关联错误文本和标签；焦点可见、键盘可达、对话框焦点管理。宽屏可多栏，窄屏改纵向与可滚动内容；不得遮挡主要操作。搜索与列表通过 API 传参并保持稳定排序，不用假数据伪装成功。
