# AI 辅助功能设计（初版）

状态：未实现、未进行真实服务联调。目标支持综述草稿、研究问题/阅读提问、标签推荐和文本基础格式检查。

## 设置及执行
用户设置服务地址、模型、超时（默认 60 秒，范围 5–300）和密钥；服务端用环境主密钥加密密钥，仅返回是否配置，不返回完整密钥。首版拟提供兼容 OpenAI 风格聊天接口的适配器，具体提供方协议需实际核实；不得假称兼容所有服务。未配置、配置无效、连接失败、超时和服务错误应返回可区分的脱敏状态。

1. 用户选择属于自己的文献、卡片及可选文本，选择任务；预览展示提供方、数据会离开本机的提示、选材名称及发送的字段/内容范围。
2. 用户确认后提交；服务端再次校验归属、选材和配置，并根据已确认的范围构建请求。内容大小上限及截断必须在预览中明确，若实际内容变化需要重新确认，不得静默增加材料。
3. 建立持久任务，由后台执行并更新状态；AI 网络调用与数据库事务分离。请求超时或进程崩溃时可能无法判断上游是否已处理；不自动重复可能产生费用的请求，标记结果未知并由用户决定是否重试。
4. 成功时保存草稿、任务类型及选定来源快照；状态为未核实草稿。用户可编辑、接受或丢弃；推荐标签等修改必须经用户确认并校验目标。无真实配置不得伪造成功。

模型输出不可保证真实性或引用正确。系统以材料来源清单供用户核对，不能将生成的引用自动认作存在或已验证，也不能在导出时凭模型文字创造文献记录。错误与日志不记录密钥和完整提示词/材料。

## 2026-11-20 实现差异
现已实现加密配置、本人选材预览与手工草稿及来源快照；未实现外部调用、确认发送、后台任务、限流或 AI 生成。当前 URL 仅做格式及字面地址初筛，不能代替 DNS 重绑定、重定向和连接目标控制；外部调用上线前必须补齐。Fernet 主密钥来自环境变量，轮换尚未实现。

## 2026-11-20 调用实现与限制
预览包含完整发送范围、外部地址与模型，并绑定材料和配置校验值；提交时重新检查。任务由 worker 领取后调用 HTTPS 公网地址，校验全部 DNS 结果并固定连接 IP、验证 TLS 主机名，不使用代理或跟随重定向。任务过期、中断或超时不自动重试；输出仅为草稿。每用户仅限制一个活动任务，尚非完整频率限制。真实服务、DNS 重绑定和多 worker 端到端尚未验证。

## 已实现的人工审核（2026-11-20）
草稿接受时提交当前标题和正文，服务端核对后标记 accepted；内容变更恢复 draft。接受仅记录用户决定，不代表事实核实。标签建议须先接受，再由用户选择本人已有标签和目标卡片并确认，服务端再次检查内容及所有权，重复应用不重复关联。不解析模型文本、不自动创建标签；其他类型建议暂不提供自动应用。浏览器、真实模型和并发验证待完成。
