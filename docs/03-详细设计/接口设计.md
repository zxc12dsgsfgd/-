# 接口设计（初版）

本稿记录首版接口设计。已实现接口以 FastAPI 生成的 OpenAPI 为准，未同步的约定仍为设计目标。接口使用 `/api/v1` 前缀和 UTF-8 JSON，文件上传使用 multipart。私有接口通过会话 cookie 认证并检查归属，分享访问接口使用分享令牌。敏感数据不得写入 URL 日志。字段长度约定见数据库设计，由请求模型校验。

## 共同约定

列表 `?limit=20&cursor=...`，limit 范围 1–100，默认按 `created_at DESC,id DESC` 游标排序；返回 `{items, next_cursor}`。过滤字段只允许指定值。详情返回资源 JSON；创建 201、更新 200、删除 204；后台任务 202 返回 `{job_id,status}`。错误形如 `{error:{code,message,request_id}}`，不返回堆栈、密钥或私有资源内容。400 参数语义错误，401 未认证，403 被禁止，404 不存在或无权访问的私有资源，409 冲突，413 超限，422 数据格式错误，429 限流，502 上游失败，504 上游超时。具体错误码随实现校核，OpenAPI 以实现为准。

2026-11-20 实现补充：错误响应同时保留兼容现有客户端的 `detail`，并增加 `error.code`、`error.message`、`error.request_id`。一般 HTTP 错误使用 `http_<状态码>`，已有业务错误可使用其原有 code。校验错误不返回提交的原始值。当前请求标识为响应中生成的随机编号，尚未接入日志关联。

## 2026-11-20 实现差异
手动文献列表当前使用按 id 降序的 `before_id` 游标；更新采用 PUT 完整替换而非 PATCH；搜索限标题。导入预览、标签和 PDF 尚未实现。迁移暂未建立规范化 DOI/标题及状态事件，查重与周报相关功能仍待实现。

## 2026-11-20 导入接口实现
`POST /papers/import/preview` 接受 `{kind: bibtex|doi, value}` 并返回 `{paper, duplicates}`，只预览不保存；DOI 解析限定 Crossref 固定地址、不跟随重定向。`POST /papers` 检测重复返回 409 和本人候选；`confirm_duplicate=true` 明确确认后单独保存。创建时锁定用户行以串行化同用户的检查和创建。一般 URL 解析和批量导入未实现。

## 2026-11-20 PDF 接口实现
`GET/POST /papers/{id}/files` 列出和上传；`GET/DELETE /papers/{id}/files/{file_id}` 授权读取和删除。文件存在时删除文献返回 409，必须先删除 PDF；清理失败保留 deleting 状态并允许重试。与原拟定的删除文献后自动排队清理不同，因清理任务尚未实现。

## 2026-11-20 笔记与卡片实现
笔记通过 `GET/POST /papers/{id}/notes` 与 `PUT/DELETE /notes/{id}` 管理；卡片通过 `GET/POST /cards`、`GET/PUT/DELETE /cards/{id}` 和 `GET /cards/{id}/versions` 管理。更新采用 PUT 并携带 version；列表使用 id 降序游标 `before_id`。标签筛选、PDF 选文建卡尚未实现。

## 2026-11-20 标签接口实现
`GET/POST /tags`、`PUT/DELETE /tags/{id}`；`GET /{papers|cards}/{id}/tags` 以及 `POST/DELETE /{papers|cards}/{id}/tags/{tag_id}` 管理关联。文献和卡片列表可用 `tag_id` 筛选。关联会校验双方所有权；卡片标签变更当前不产生历史版本，待完善。

## 2026-11-20 卡片关系接口实现
`POST /card-relations` 创建有向关系，`DELETE /card-relations/{id}` 删除；`GET /graph` 返回当前用户最近 200 个节点及最多 500 条内部关系，并标记截断。关系双方均校验归属，不允许自关联及同向同类型重复。删除卡片时删除关联。

## 2026-11-20 阅读计划实现
`GET/POST /plans`、`GET/PUT/DELETE /plans/{id}` 与 `GET /dashboard` 已实现。计划提交本人文献编号数组、日期和目标篇数；返回当前已读数与所选数。删除文献移除计划项。看板统计当前未删除数据，最近卡片按 id 降序。
