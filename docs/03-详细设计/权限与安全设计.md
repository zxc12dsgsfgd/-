# 权限与安全设计（初版）

计划性设计，未执行安全测试；密钥和会话参数不能写入仓库或日志。

## 身份、会话与授权
拟使用成熟库的 Argon2id 密码哈希及随机不透明会话令牌。会话令牌保存在 HttpOnly、SameSite=Lax cookie（HTTPS 环境必须 Secure；仅 localhost 本地 HTTP 可关闭 Secure），数据库仅存令牌摘要，默认 7 天到期；退出撤销服务端会话。状态变更请求同时验证允许的 Origin 和 CSRF token；开发环境前后端 origin 明确配置且 CORS 不允许通配携带凭据。会话及 CSRF 具体交付和轮换机制在实现时测试。

普通用户仅访问 owner_id 为自己且关联资源也属自己的对象，含 PDF 与任务。跨用户资源按 404 隐藏存在性。分享访问者无账户权限，只能按令牌访问快照；创建令牌使用密码学安全随机数至少 32 字节，服务端仅存 SHA-256 摘要；到期或撤销立即不可访问，权限禁止批注时拒绝写入。分享页设置 `Referrer-Policy: no-referrer`，日志脱敏且不加载外部资源。

## 输入、文件和网络
默认上传 PDF 上限 50 MiB、批注上限 5000 字符，服务端验证长度、类型、文件头与路径；这些数值为本地首版设计默认值，可配置并待测试。用户文本默认按文本转义；如呈现 Markdown，使用严格白名单清理 HTML、URL 和脚本。上传路径使用随机键，禁用穿越及公开目录映射。

AI 地址默认仅允许 HTTPS 公网目的地；拒绝 loopback、链路本地、私网及云元数据等目标，DNS 解析结果和每次重定向重新检查，并限制重定向。用户若需要自托管本地 AI，需由本机管理员显式配置允许的地址或网段，不能由普通用户直接解除限制；HTTP 仅经明确配置例外。DOI/URL 元数据抓取同样适用出站限制。实现时必须验证 DNS 重绑定及代理的实际处理，不能只在输入时做一次主机名检查。

## 密钥、限流和日志
AI 密钥使用成熟认证加密库及从环境变量读取的主密钥；存密文、随机 nonce 和密钥版本，明文只在调用时短暂使用。轮换需先保留旧版本密钥、重新加密成功再移除旧密钥；丢失主密钥后密文不可恢复，需重新配置。GET 不返回密钥；日志不记录令牌、授权头、密钥或材料全文。

单机默认限流建议：登录每 IP 每分钟 10 次，分享每 IP 每分钟 60 次，AI 每用户每分钟 10 次；超限返回 429 及 Retry-After。阈值可配置，生产或多进程必须使用共享存储的原子计数，不能声称内存计数跨进程有效。此阶段不选定具体实现；代理 IP 信任列表、恢复和并发需实测。AI 功能失败不阻断非 AI 核心业务。

## 2026-11-20 实现差异
认证接口目前以固定自定义请求头、Origin 白名单和 SameSite cookie 限制跨站请求，尚未实现独立 CSRF token；仅用于本地开发，扩展状态变更接口时需统一设计并测试。来源白名单为本地固定端口；登录限流为单进程内存，不支持多进程共享。

## 2026-11-20 PDF 实现范围
上传检查扩展名、媒体类型、文件头和大小，随机键不使用原始路径；响应设置 nosniff、私有缓存控制和 CSP sandbox。文件头检查不保证 PDF 完整或安全；上传解析器可能先将请求体暂存，反向代理须限制请求体，当前端点要求 Content-Length 并检查上限。浏览器兼容性和恶意 PDF 处理未验证。
