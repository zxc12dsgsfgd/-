# 核心业务流程设计（初版）

以下为计划行为，未实现、未验证。错误码和接口见《接口设计》，表及事务见《数据库详细设计》。

## 文献导入与删除
1. 用户手填或提交 BibTeX、DOI/链接预览；外部解析受网络和目标地址安全策略约束。解析失败保留手工录入路径。
2. DOI 去掉 `doi:` 或 `https://doi.org/` 前缀、首尾空格并小写；仅在存在 DOI 时先比较同用户规范化 DOI。无 DOI 时比较同用户去首尾空格、统一空白及大小写的标题；比较结果仅作候选，不自动合并。若用户确认保留重复，提交明确标志；最终写入时再次检查以处理并发。
3. PDF 大小上限拟为 50 MiB，可配置；流式检查扩展名、媒体类型与 PDF 文件头，随机生成存储键，先存临时路径再登记和转入受控目录；失败和孤儿文件由清理任务处理。原始文件名只供展示，不参与路径拼接。
4. 文献删除前列明：笔记、文件和状态事件删除，关联卡片保留并断开文献链接、保存来源快照；既有草稿来源及分享快照保留。用户确认后执行数据库变更并排队清理文件，失败可重试。

## 阅读、卡片和标签
授权读取 PDF 并在页面预览，支持选择文本、页码与摘录建卡；选择不可用时允许手输。服务端校验关联文献和标签归属；独立卡片 paper_id 可空。更新卡片携带 version，冲突返回 409；内容及新版本快照同事务写入。删除卡片前说明版本及关系随之删除、分享快照与草稿来源保留。标签名按去空白及大小写归一去重；删除标签只删除关联。

## 阅读计划与周报
计划关联用户所选文献，进度 = 当前状态为“已读”的计划项数 / 当前计划项总数；空计划显示 0/0，不将其视为 100%。工作台计数按当前未删除记录实时计算。周报默认采用用户配置时区，初始 `Asia/Shanghai`；按当地周一 00:00 至下周一 00:00（左闭右开）换算为 UTC。新增数统计当前仍存在且创建时间落入周内的文献/卡片；已读文献数统计周内至少一次进入已读状态的当前仍存在的不同文献，重复进入仅计一次。删除后历史报表可能变化，界面注明口径；时区设置和边界需实测。

## 分享、导出与来源
创建分享时逐项校验所有权并保存用户明确选择的卡片或草稿内容快照；除所选对象的必要来源标识外，不带 PDF、文献全文、密钥或其他私有数据。令牌只在创建时返回一次，服务端只保存摘要；访问和批注每次检查到期、撤销、批注权限与批注对象所属分享。快照在原对象编辑或删除后保持不变，所有者可撤销。导出以已选数据为范围，对 LaTeX 特殊字符转义；参考文献只来自真实关联文献或已保存来源快照，不凭 AI 生成补充。

## 2026-11-20 周报实现差异
周报固定 UTC+08:00；按仍存在记录计新增，按迁移后记录的状态事件去重计已读。旧记录无法追溯，界面提示历史不完整；用户时区配置尚未实现。
