# 缺陷记录

## BUG-001：新建标签后卡片标签列表未刷新

- 发现日期：2026-11-20；状态：已修复，创建及关联浏览器复测通过；严重程度：中。
- 步骤：登录后已有卡片，在“标签管理”创建标签，再打开卡片的“添加标签”下拉框。
- 实际：新标签未出现；刷新页面后出现并可成功关联。
- 预期：创建标签后，已有卡片的标签选项及时更新。
- 范围：内置浏览器、本地前后端及 MySQL；根因：标签管理组件修改后未通知独立的资源标签组件重新读取；现已在创建、重命名、删除成功后发送变更事件，资源标签和 AI 审核标签列表订阅刷新，并清理失效选择。创建、关联、重命名与删除后的浏览器复测通过，覆盖文献、卡片与已接受的 AI 标签草稿。
- 交互补充：浏览器原生 prompt/confirm 阻碍自动化验收，已替换为页面内重命名表单和删除确认区。更新标签后文献、卡片及 AI 审核选项立即刷新；删除后关联展示与 AI 标签选项同步移除。

## BUG-002：知识图谱关系箭头被节点遮挡

- 发现日期：2026-11-20；状态：已修复并浏览器复测；严重程度：中。
- 步骤：创建两张卡片，在图谱中建立从第一张卡片指向第二张卡片的“支持”关系，查看图谱画布。
- 实际：连线和关系文字可见，箭头不可见。文字关系列表仍显示正确方向。
- 预期：画布上的箭头清晰指向目标卡片，使用户无需依赖下方文字列表辨别方向。
- 证据：内置浏览器和隔离 MySQL 中的两节点测试。代码中连线终点位于目标节点中心，节点图形在连线之后绘制，结合页面观察，箭头被目标节点覆盖。其他布局和浏览器尚未验证。
- 修复：连线两端移动到节点矩形边界外，箭头尖端位于目标节点外侧。内置浏览器以五节点验证水平正反方向、垂直和斜向箭头，以及节点键盘操作。复杂关系线仍可能经过其他节点并被遮挡，双向重叠和密集图尚未验收。
