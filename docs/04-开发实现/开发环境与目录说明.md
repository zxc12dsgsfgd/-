2026-11-20：Windows，本机 uv 0.13.0、Python 3.12.10、Node 26.13.0、npm 11.20.0；Docker 客户端 29.9.2，但其 Linux 引擎不可连接。本机存在运行中的 MySQL80 服务，未获取专用数据库凭据或连接该服务。

`.venv/` 由 uv 创建；`pyproject.toml`、`uv.lock` 管理后端依赖；`frontend/` 为 React/Vite 与 npm 锁文件；`backend/app/` 是 API 骨架；`backend/migrations/` 是 Alembic 及 users 初始迁移；`compose.yaml` 为 MySQL 本地配置；`.env.example` 为不含真实秘密的模板。具体命令见根目录 README。

验证：`uv run pytest -q` 2 通过，存在上游 Starlette 测试客户端弃用警告；`npm run build` 通过；后端实际 HTTP 健康接口返回 ok，未配置数据库状态为 not_configured；浏览器经 Vite 代理显示后端已连接；Alembic 生成 MySQL 离线 SQL 成功；`docker compose config --quiet` 成功。Docker 引擎不可连接，真实 MySQL、迁移升级/回滚和数据持久化未执行。npm 安装提示 esbuild 安装脚本未列入允许清单，但本机构建通过。

Compose 在当前中文目录默认推导项目名为空，显式设置 `name: zhiyan-yunshu` 后配置检查通过；未因此证明容器可运行。项目采用安静的中性色与墨绿色、纸张和笔记的视觉方向；此页仅为基础状态页，并非完整界面设计。
