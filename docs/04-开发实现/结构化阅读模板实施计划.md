# 结构化阅读模板实施计划

对应 FR-032。现有自由格式笔记保持可用，增加独立的结构化阅读笔记及用户模板。默认字段包括研究问题、研究背景、数据或实验材料、研究方法、主要结果、作者声称的贡献、研究局限、我的疑问、与当前课题的关系、可复用的观点或方法；每个字段可为空。

- 用户模板保存名称和字段名列表，编辑或删除模板不改变已保存笔记的字段快照。笔记的字段和值由用户填写；不将其描述为论文原文，不调用 AI。模板和笔记按当前会话归属校验，回收中的文献不能修改或访问笔记，恢复后保留；永久删除文献时一起删除笔记。
- 单字段转卡片时只读取已保存的非空内容，创建关联该文献的卡片，正文性质标为用户解释、核查状态待核查、原文摘录为空；记录来源字段名。原需求中“并保留来源文献和用户明确”句子未完，此处不假定其他缺失含义。
- 普通检索在本人可访问的文献范围内搜索字段名和内容；限制每条笔记字段数量和长度。个人备份版本 1 当前不含结构化笔记和自定义模板，须在界面和文档明确，不得称为完整备份。
- 验证字段可空、模板编辑快照、搜索、转卡来源和性质、跨账号隔离、回收恢复及永久删除；隔离 MySQL 验证迁移与接口，浏览器未验收须如实标记。
