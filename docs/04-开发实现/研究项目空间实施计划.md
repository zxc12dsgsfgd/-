# 研究项目空间实施计划

目标：在现有模块化单体中实现 FR-028，保持资源单份存储和用户隔离。使用 MySQL、Alembic、FastAPI、React 和 uv；测试数据仅使用隔离库或内存测试。

1. 模型和迁移：`backend/app/models.py` 增加项目表及四种资源关联表；`backend/migrations/versions/0018_research_projects.py` 创建表，唯一约束防重复关联，关联外键在源对象删除时清理。
2. 接口：`backend/app/projects.py` 提供项目列表、创建、详情、修改、删除及按类型添加/移除关联；写入关联时锁定并校验双方所有者。删除项目仅删除关系。详情根据关联查询本人实际资源和阅读计划进度。
3. 验证：`backend/tests/test_projects.py` 覆盖两个项目共享卡片、解除单个关联、删除项目不删除材料、四类资源关联及跨账号拒绝，检查源资源删除后的关联清理；随后隔离 MySQL 迁移并回归。
4. 界面：`frontend/src/Projects.tsx` 增加项目创建、编辑、归档、关联和删除确认，并在 `frontend/src/main.tsx` 接入；显示真实资料及进度。执行构建及适用的浏览器验收。
5. 更新需求矩阵、测试执行记录和项目记忆，列出尚未覆盖的条件。FR-031 回收站实施前，当前项目删除仍为确认后永久删除项目本身，关联资料不删除。
