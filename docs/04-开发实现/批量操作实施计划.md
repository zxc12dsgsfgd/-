# 批量操作实施计划

对应 FR-033。文献和卡片按实际勾选编号操作，每次 1～50 条；不提供跨页全选或按筛选结果隐式全选。前端显示已选数量及名称，切换类型时清空选择，切页保留已勾选项并明示。

批量添加/移除标签、关联研究项目、文献状态变更和移入回收站使用单次数据库事务；每个资源及目标标签/项目均校验当前用户归属，任何一项不存在、不可访问或已回收时整批拒绝，返回安全原因和零成功数量，不泄露哪个编号属于其他人。无变更的幂等操作计入成功，额外报告实际变更数。状态变更和回收须明确确认；状态变更沿用现有状态事件和工作流，失败时回滚整批。文献回收复用单条回收逻辑，保留附件和笔记并更新卡片来源。

卡片批量导出复用已有导出接口，最多 50 条；服务端逐项校验归属。测试包括三选标签、未选中保持不变、他人记录整批拒绝、项目关联、状态工作流及回滚、回收和导出；在隔离 MySQL 验证代表性场景。无数据库迁移。
