# 知研云枢

科研知识卡片与工作流编排平台。目前提供注册、登录、退出、手动文献元数据管理、单条 BibTeX 和 DOI 导入预览及重复提示；已支持 PDF 上传及授权预览接口、文献笔记和知识卡片基础；已支持标签管理和文献、卡片关联；支持卡片有向关联与基础图谱；已支持事件触发站内提醒的工作流基础；阅读计划、工作台以及工作流定时检查和动作基础已实现。

## 环境
已在 Windows 上验证 Python 3.12、uv、Node.js 和 npm；数据库计划使用 MySQL 8.4 和 Docker Compose。项目目录内 `.venv`、`.uv-cache`、`.npm-cache`、`frontend/node_modules`、`frontend/dist` 和 `data/` 均为本地生成内容，不应提交。

## 本地启动（PowerShell）
1. 在项目根目录执行：`$env:UV_CACHE_DIR = "$PWD\.uv-cache"`，再执行 `uv sync --locked`。
2. 复制 `.env.example` 为 `.env`，自行设置不同的本地数据库密码并同步更新 `DATABASE_URL`；URL 中密码含特殊字符时需 URL 编码。不要提交 `.env`。模板值只是占位符，不能直接用于真实环境。
3. 启动 Docker Desktop 引擎后执行 `docker compose up -d`；首次初始化后更改环境变量不会自动更改已有数据库用户密码。本机已验证启动和健康检查。
4. 执行 `uv run alembic upgrade head`。本机已完成初始迁移；新环境仍需执行。
5. 执行 `uv run uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000`。API 文档：`http://127.0.0.1:8000/docs`；健康检查：`/api/v1/health`，数据库状态：`/api/v1/health/database`。
6. 另一终端执行 `cd frontend`，然后 `npm ci --cache ..\.npm-cache` 和 `npm run dev`；访问 Vite 提示的地址。开发代理默认将 `/api` 转发至 8000 端口。
7. 停止前后端使用各终端 Ctrl+C；停止容器使用项目根目录 `docker compose stop`。不要随意删除 `data/mysql`，其中将保存数据库数据。

自动化检查：根目录 `uv run --locked pytest -q`；前端 `npm run build`。若已有可用 MySQL，也可在 `.env` 中配置专用数据库的连接地址；需要自行确保数据库及权限存在。隔离测试库的逻辑备份和恢复已验证，真实项目数据、PDF 文件及跨主机恢复尚未验证。Docker 镜像及运行时文件由 Docker Desktop 管理。

过程记录见 [项目管理](docs/00-项目管理/阶段成果总表.md) 和 [开发实现](docs/04-开发实现/开发环境与目录说明.md)。

登录和公开分享使用 MySQL 共享固定窗口限流，同一来源每 60 秒分别最多 10 次和 60 次。限流使用直接连接 IP，不信任转发头，反向代理前的部署需配置可信客户端 IP 方案。项目 worker 每小时清理超过一天的限流记录。数据库不可用时限流接口不可用。本地 HTTP cookie 未启用 Secure，HTTPS 环境需设置 `SECURE_COOKIES=true`。前端开发端口为 5173，当前来源白名单使用固定本地端口；公网部署前仍需完成来源配置和安全审查。

通过 HTTPS 隧道临时访问时，可在 `.env` 设置 `PUBLIC_ORIGIN=https://实际域名`（不带路径和末尾斜杠）及 `SECURE_COOKIES=true`，重启后端后生效。每次临时域名变化必须同步更新；不能设置通配符。此方式仍使用 Vite 开发服务器，适合临时测试，不代表安全生产部署。直接连接 IP 限流在反向代理后可能将多个访问者视为同一来源；请勿直接信任客户端提交的转发头。公网使用前应完成生产部署、安全审查和访问控制。

文献导入目前支持粘贴单条 BibTeX 或 DOI/doi.org 链接。DOI 查询依赖 Crossref 网络服务，解析结果请核对后保存；支持批量 BibTeX 预览与逐条导入，每次最多 50 条、60000 字符；一般文献网页支持 HTTPS 元数据预览；仅访问公网 443，拒绝重定向，网页大小限制 1 MiB，不执行脚本。页面缺少信息、需登录或跳转时请手工填写，请勿输入含密钥的链接。批量导入不是原子操作，网络异常后请先检查文献库再重试；记录会重建为单条 BibTeX，复杂语法尚未全面验证。相同 DOI（无 DOI 时相同规范化标题）提示可能重复，确认后才单独保存，不自动合并。

PDF 上传默认上限 50 MiB，可通过 `PDF_MAX_BYTES` 设置服务端上限；前端提示目前固定 50 MiB。文件保存在 `data/pdfs`，通过授权接口访问；删除文献前须先删除其 PDF。当前只检查扩展名、媒体类型、大小和 PDF 文件头，并不能证明文件完整或安全；浏览器 PDF 插件兼容性尚未验收。意外中断可能留下临时或孤儿文件，自动恢复尚未实现。

个人备份的 PDF 附件包与 JSON 数据分开保存。恢复时在个人数据备份页面选择附件包、校验、逐项填写本人目标文献编号、核对后确认导入；文件只新增，不覆盖或自动去重。导入意外中断时可在同一页面检查并清理待处理批次，再重新导入；出现无法自动清理的提示时须保留现场排查。当前仅支持同一主机、应用独占控制且支持硬链接的同卷存储；不支持多主机恢复。附件包不含回收站文件，JSON 和附件包都不是完整系统备份。详见 `docs/04-开发实现/PDF附件备份设计.md`。

文献条目下可维护笔记；知识卡片支持独立创建或按文献编号关联，支持手动填写来源页码、摘录、查看历史。删除文献会删除其笔记，并将关联卡片保留为独立卡片及保留来源标题快照；请先删除 PDF。PDF 预览支持当前页选中文字建卡，也可手动输入摘录；标签变更目前不进入卡片历史版本。

PDF 预览使用 PDF.js；内置浏览器已用单页测试文件验证渲染。扫描件、加密文件、多页及不同浏览器兼容性尚未验证；支持当前页选文建卡，页码为 PDF 文件页序号；复杂版式、中文文字和其他浏览器尚未验证。

工作流支持文献创建、状态变化、卡片创建和定时检查；动作支持提醒、添加标签及更新文献状态。事件触发同步执行，失败会回滚业务操作；定时检查需单独启动 worker（项目根目录 `uv run --locked python -m app.worker`，先设置 `$env:PYTHONPATH="backend"`）。worker 每分钟扫描，当前按文献创建时间计算待读超期、UTC 日期每天去重；停止期间不运行，恢复后只处理当日。规则链超过 5 层会回滚。定时单项失败会保存脱敏代码、次数和下次重试时间，按 1 分钟起指数退避、最多 1 小时；同一扫描继续处理其他项。跨日时优先重试该规则和文献的未解决失败，成功后当天不再重复执行；多 worker 和真实进程重启恢复尚未实测；同步事件的规则动作失败时会回滚业务，并尝试在独立事务记录脱敏错误；新建操作回滚后无有效对象编号。数据库不可用、进程在两事务间中断或事件建立/最终提交失败时不保证记录；不会自动重试。

阅读计划可选择文献、设置日期和目标篇数。进度为当前已读文献数 / 当前计划所选文献数，目标篇数单独展示；空计划为 0/0。删除文献会将其从计划移除；删除计划不会删除文献。工作台数据需手动刷新，计划编辑界面目前仅列出最近 100 篇文献，其他已选文献保持不变。

周报按 UTC+08:00 周一至下周一（不含结束）统计当前仍存在的新增文献和卡片，以及周内至少一次进入已读状态的不同文献。状态历史从本次迁移后开始记录，旧数据不完整；删除内容会改变历史统计。用户时区配置尚未实现。

工作流界面提供待读超期提醒、已读加标签和方法卡片加标签模板；模板先填充表单，需用户核对标签编号并保存。跨日重试仅处理规则仍启用、文献仍为待读且仍满足当前超期条件的失败，使用当前规则配置；规则删除、停用或条件不再满足时旧失败不会自动解决，停机期间没有失败记录的历史日期不回补。

AI 配置和手动草稿基础：在 `.env` 设置 `AI_ENCRYPTION_KEY`，可用 `uv run python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"` 生成；本机已有本地密钥。密钥丢失后已保存的 API Key 无法解密，需重新配置；备份 `.env` 时注意保护秘密。当前可预览本人选材并确认提交后台 AI 任务；worker 使用兼容 OpenAI 聊天接口的服务并保存未核实草稿及来源。已用合成材料验证 DeepSeek `deepseek-v4-pro` 真实成功调用及无效模型的失败处理；其他服务和生产级安全审查仍需验证。

AI 任务需启动与定时工作流共用的 worker。预览展示外部地址、模型及完整选材，确认后材料或配置变化必须重新预览；请求材料上限 200 KB。每用户同时仅允许一个待处理或运行中的任务；成功入队的 AI 任务另受 MySQL 滚动窗口限制，默认每 60 秒最多 10 次，可用 `AI_RATE_LIMIT_COUNT` 与 `AI_RATE_LIMIT_WINDOW_SECONDS` 配置。预览、配置及未成功入队请求不计入此限制。HTTPS 连接拒绝非公网解析地址，固定连接到已检查的 IP 并验证原主机证书，禁用代理和重定向。超时或运行中断可能已被服务方处理，系统不自动重试；任务状态需手动刷新。任务材料及加密密钥副本暂存在数据库，处理结束清除任务密钥副本。

分享支持卡片集或草稿标题和正文的快照，允许设置 1–365 天有效期及可选批注，创建时链接仅显示一次；原内容变更或删除不会改变快照，可随时撤销。链接片段包含访问令牌，请妥善保存并仅发给可信接收人。访客不需要账户；批注由分享者查看和标记处理。公网使用需要 HTTPS、禁止代理记录 `X-Share-Token` 请求头，并在生产前完成安全审查。浏览器完整流程尚未验收。

草稿可由用户接受，修改标题或正文会恢复待审核；接受不代表内容已核实。对于标签建议，用户可对照内容选择已有标签及本人卡片，确认后添加；不会自动解析建议或创建标签。浏览器完整流程与真实模型联调尚未验收。
